# SiBCAE
sistema biometrico de control de aistencia estudiantil (por sus siglas SiBCAE), Es un proyecto de caracter estudiantil dedicado para el evento expolitec de la preparatoria politecnica de guadalajara. Consiste en un sistema de registro de asistencia mediante un lector de huella de alumnos y maestros para el registro de asistencia, retardo y falta.
